## 四、M5 要做什么（下次直接从这里开始）

M5 是 **PRD Phase 0 的验收点**，目标：`autojob apply <url>` 真正打开浏览器把表单填出来，**在提交前停止**。

### 4.1 任务清单

1. **`packages/browser`**：Playwright 封装
   - Headful + Persistent Context，profile 存 `~/.autojob/browser-profile/`
   - `BrowserTask` 14 态状态机（PRD §26），每次状态变化写日志
   - 遇登录/验证码 → `WAITING_USER`，**禁止任何绕过逻辑**（PRD §74）

2. **FormFiller** —— **不用从零摸索，直接照搬 `tests/e2e/hard-widgets.spec.ts`**
   那个文件里每个用例都是一个必须支持的填写动作，M2 时就是为此写的：
   - 自定义下拉：选项点击前 DOM 里不存在 → 不能用 `selectOption`
   - autocomplete：必须等候选渲染完再点，输入不足 2 字不出候选
   - **Repeatable：删除中间条后索引不重排 → 按顺序数第 N 条会拿错元素**
   - 隐藏 file input：必须 `setInputFiles`，不能点 label 按钮

3. **补 `mock_login` 站**：配合 Persistent Profile 验证登录态复用

4. **接 SQLite**（Drizzle）：Application 记录 + 截图落盘，Run ID 见 `packages/core/src/run-id.ts`

5. **CLI**：`autojob apply <url>`、`autojob profile import/export`

### 4.2 M5 的验收标准 = PRD §51 原始清单

- [ ] Mock 站正确填写：姓名/邮箱/电话/学校/专业/学历/项目/工作经历/科研经历/奖项/个人主页/附件
- [ ] 科研项目不进入工作经历
- [ ] 奖学金与竞赛奖项正确分类
- [ ] GitHub / 个人主页自动填写
- [ ] Resume / Portfolio 上传成功
- [ ] **在 Submit 前停止，不点提交**
- [ ] Application 记录入库 + 截图落盘
- [ ] E2E 测试在 CI 中通过

## 六、重要约定（改代码前必读）

完整版见 `CLAUDE.md`，这里只列最容易踩的：

- **`materials/` 是隐私目录**，已 gitignore，**永远不要提交**
- **测试代码禁止出现真实手机号/身份证/邮箱**，一律用虚构数据
- 所有日志必须走 `@autojob/core` 的 `createLogger`（自带 PII 脱敏）；ESLint 已禁止业务代码直接 `console.*`
- 浏览器全局（`document`/`window`）只允许出现在 `packages/form-schema/src/raw-field.ts`
- 每轮开发按六步走：查仓库 → 说明改哪些文件 → 实现**一个**小功能 → 跑 `pnpm check` → 修失败 → 总结
- **禁止为了让测试通过而删测试**

## 七、架构速览（避免重新读一遍代码）

```
页面 DOM
  ↓  EXTRACT_FIELDS_SCRIPT（浏览器侧，form-schema/raw-field.ts）
RawField[]
  ↓  classifyForm（form-schema/classifier.ts）
FormField[]  ← 带 semanticType + confidence
  ↓  mapForm（form-mapper/mapper.ts）
FormPlan     ← 每个字段 filled / skipped / ask_user + warnings
  ↓  【M5 要做的】FormFiller
真实填入浏览器 → 提交前停止
```

**三道闸**（记录要进某字段必须全过）：

1. Profile 的 `shouldNotMapTo`（M1 定的，规则不可解除）
2. MappingRule 的 `blockedCandidateTypes`（各级规则并集）
3. 字段置信度 ≥ 0.7

**关键包**：

| 包                           | 职责                                   |
| ---------------------------- | -------------------------------------- |
| `@autojob/core`              | Result、错误码、PII 脱敏、日志、Run ID |
| `@autojob/candidate-profile` | 数据模型 + 查询层（红线的唯一执行点）  |
| `@autojob/form-schema`       | DOM 提取、label 归因、语义分类         |
| `@autojob/form-mapper`       | 规则引擎、取值映射、warning 生成       |
